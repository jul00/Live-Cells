# Live Cells

## Introduction

**Live Cells** is a high-octane samurai action platformer where the player fights through a tyrant’s castle using movement, attacks, blocking, and dashing. The game focuses on dynamic combat patterns, enemy archetypes, and precise timing, with progression built around clearing stages and defeating bosses.
